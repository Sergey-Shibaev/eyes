# Глаза

Отдых для глаз при работе за экраном: следите за точкой, смотрите вдаль, моргайте. Приложение ставится на телефон и работает без интернета.

Сделано на каркасе приложения [«Дыхание»](https://github.com/Sergey-Shibaev/breath): живые фоны, звук, офлайн-режим и экран настроек перенесены оттуда без изменений.

## Установить на Android

1. Откройте в **Chrome** адрес https://sergey-shibaev.github.io/eyes/
2. Нажмите шестерёнку в правом нижнем углу приложения.
3. Вверху настроек нажмите жёлтую кнопку **«Установить»** и подтвердите.

Если кнопки нет, установите через меню браузера: три точки справа вверху → **«Установить»**. Не путайте с «Создать ярлык» (это обычная закладка) и с «Версия для ПК».

## Установить на iPhone и iPad

1. Откройте в **Safari** адрес https://sergey-shibaev.github.io/eyes/
2. Нажмите «Поделиться» (квадрат со стрелкой вверх).
3. Выберите **«На экран „Домой“»** → «Добавить».

На рабочем столе появится иконка «Глаза». Дальше приложение открывается на весь экран и работает без интернета.

## Что честно можно обещать

Упражнения для глаз **не исправляют** близорукость, дальнозоркость и астигматизм. Лучше всего подтверждено упражнение на моргание: в рандомизированном испытании 2025 года 15 повторов «закрыть — зажмуриться — открыть» трижды в день уменьшили симптомы сухости глаз. Правило 20-20-20 знаменито, но два испытания 2023 года эффекта от него не нашли. Слежение за точкой, круги и восьмёрки — приятный перерыв без доказанной пользы.

У каждого упражнения есть поле `evidence` — насколько польза подтверждена — и `evidenceNote` с пояснением. Приложение показывает их в списке как есть. Не повышайте уровень без источника.

## Как устроено

Обычная веб-страница без сборки: открывается двойным щелчком по `index.html`.

| Файл | Что делает |
| --- | --- |
| `index.html`, `styles.css` | разметка и оформление обоих экранов |
| `app.js` | занятие, настройки, установка на телефон |
| `exercises/` | упражнения, по файлу на упражнение; контракт описан в `registry.js` |
| `backgrounds/` | живые фоны, по файлу на фон |
| `sound/` | звук: ядро `engine.js` и четыре режима звучания |
| `music.js`, `music/` | фоновая музыка бесшовным кольцом |
| `sw.js`, `manifest.webmanifest` | работа без интернета и установка на телефон |

## Добавить своё упражнение

1. Скопируйте `exercises/_template.js` под своим именем, например `exercises/diagonal.js`.
2. Опишите шаги. Полный контракт — в начале `exercises/registry.js`.
3. Впишите файл в `index.html` рядом с остальными упражнениями и в список `APP_FILES` в `sw.js`.
4. Проверьте: `node tests/exercise.test.js`

Упражнение — это последовательность шагов трёх видов:

- `track` — за точкой следят глазами, положение задаёт `at(p)`;
- `rest` — глаза отдыхают: закрыть, посмотреть вдаль;
- `blink` — сознательное моргание в ритме.

Координаты в `at(p)` — доли от центра поля: `(0, 0)` середина, `(-1, -1)` левый верхний угол.

## Разработка

```
node dev-server.js
```

Затем откройте http://localhost:8138 — или `design.html`, где оба экрана видны рядом, и `backgrounds/preview.html`, где видны все фоны.

Проверки:

```
node tests/exercise.test.js
node tests/background.smoke.js backgrounds/bubbles.js
node tests/background.seam.js backgrounds/bubbles.js
node tests/sound.test.js sound/bell.js sound/ladder.js sound/tone.js sound/wave.js
node tests/music.test.js
```

`tests/exercise.test.js` следит за главным: точка не выходит за поле, не прыгает внутри шага и не движется быстрее, чем взгляд успевает её вести.

Фоновая музыка — живая запись арфы, публикуется с разрешения исполнительницы. Кольцо без пауз и с выровненной громкостью (около −16 LUFS) собирает `tools/make-music-loop.py` (нужны python с numpy и scipy и ffmpeg): `python tools/make-music-loop.py <запись> --start 16.5 --end 171.0`. Если убрать папку `music`, приложение просто работает без музыки.

Иконки перерисовываются страницей `tools/make-icons.html` при запущенном `dev-server.js`. QR-код на опубликованный адрес — `tools/qr.html` (другой адрес — `tools/qr.html?url=адрес`).

## Предупреждение

Упражнения для глаз не заменяют осмотр у врача. Появились резь, головокружение или двоение — остановитесь. После операций на глазах и при болезнях сетчатки сначала посоветуйтесь с врачом.
